# Mafia

Учебный проект на C++20: многопоточная эмуляция игры «Мафия».

## Текущее состояние

На данный момент реализованы:

- собственный шаблонный `SharedPtr` со счётчиком ссылок;
- базовый класс `Player` и отдельная нить игрока;
- обязательные роли `Mafia`, `Civilian`, `Doctor`, `Commissioner` и `Maniac`;
- стратегии выбора цели;
- передача действий от игроков ведущему;
- многопоточное дневное голосование;
- сбор и одновременное разрешение ночных действий;
- игровой цикл голосования и ночи до выполнения условия победы;
- автоматическое создание партии из `N` игроков и случайная раздача ролей;
- случайная стратегия для полностью автоматической игры;
- интерактивная стратегия для управления одним игроком с консоли;
- параметры запуска через командную строку;
- открытые и закрытые объявления ведущего;
- краткий и полный консольный лог;
- файловые логи каждого раунда и итоговая статистика через `std::filesystem`;
- concepts для проверки игровых, голосующих и действующих ночью ролей;
- применение результата голосования к состоянию игры;
- модульные и интеграционные тесты.

В интерактивном режиме пользователь управляет игроком `#1`: видит свою роль,
выбирает цели, а при роли комиссара также выбирает между проверкой и выстрелом.

## Структура проекта

```text
include/mafia/   Заголовочные файлы
src/             Реализация и точка входа
tests/           Тесты
CMakeLists.txt   Конфигурация CMake
Makefile         Простая сборка через MinGW Make или GNU Make
```

## Требования

- компилятор с поддержкой C++20;
- потоки стандартной библиотеки;
- `mingw32-make` на Windows или `make` на Linux/macOS;
- опционально CMake 3.20 или новее.

## Одна команда для сборки, тестов и запуска

На Windows с MinGW:

```powershell
mingw32-make check
```

На Linux или macOS:

```bash
make check
```

Команда собирает основную программу, собирает и запускает все тесты, а затем
запускает автоматическую партию на 10 игроков в кратком закрытом режиме.

## Отдельные команды

Собрать программу:

```powershell
mingw32-make
```

Запустить программу:

```powershell
mingw32-make run
```

Передать собственные параметры через Makefile:

```powershell
mingw32-make run RUN_ARGS="--players 12 --open-announcements --full-log"
```

Либо вызвать собранную программу напрямую:

```powershell
.\mafia.exe --players 12 --open-announcements --full-log
```

Запустить интерактивную партию:

```powershell
.\mafia.exe --players 10 --interactive --closed-announcements --brief-log
```

Поддерживаемые параметры:

```text
--players N              Количество игроков, N > 4
--mafia-divisor K        Делитель числа мафии, K >= 3
--interactive            Управление игроком #1 с консоли
--open-announcements     Открытые объявления ведущего
--closed-announcements   Закрытые объявления ведущего
--full-log               Вывод всех принятых действий
--brief-log              Только основные события
--log-directory PATH     Каталог файловых логов (по умолчанию logs)
--help, -h               Справка
```

## Файловые логи

При каждом запуске автоматически создаётся отдельный каталог партии:

```text
logs/
  game_20260927_104037/
    round_001.txt
    round_002.txt
    summary.txt
```

Файл раунда содержит все дневные голоса, ночные действия, переговорные
предложения мафии, результаты проверок и лечения, а также список выбывших.
`summary.txt` содержит победителя, роли, финальное состояние и статистику
действий каждого игрока. Каталог `logs/` исключён из Git.

Запустить все тесты:

```powershell
mingw32-make test
```

Удалить результаты сборки:

```powershell
mingw32-make clean
```

## Сборка через CMake

```powershell
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

Каталог `build/` и скомпилированные файлы исключены из Git.
